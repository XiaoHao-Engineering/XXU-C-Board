## 0. 开始之前：硬件核对（这一步错了后面全是坑）

### 0.1 电机接线与 ID

| 部件 | 电机 | 电调 | 挂哪条总线 | ESC ID | 反馈帧 | 配置宏 |
|---|---|---|---|---|---|---|
| 底盘左前 | M3508 | C620 | CAN1 | 2 | 0x202 | `main.c` 里 `DJI_Motor_Init(..., 2, ...)` |
| 底盘右前 | M3508 | C620 | CAN1 | 3 | 0x203 | 同上 |
| 底盘左后 | M3508 | C620 | CAN1 | 1 | 0x201 | 同上 |
| 底盘右后 | M3508 | C620 | CAN1 | 4 | 0x204 | 同上 |
| 云台 yaw | GM6020 | 内置 | CAN1 | 1 | 0x205 | `GIMBAL_YAW_MOTOR_ID` |
| **云台 pitch** | GM6020 | 内置 | **CAN2** | 4 | 0x208 | `gimbal.h` 的 `GIMBAL_PITCH_MOTOR_ID` |
| **摩擦轮左** | M3508 | C620 | **CAN2** | 1 | 0x201 | `shooter_config.h` 的 `SHOOTER_FRICTION_LEFT_ID` |
| **摩擦轮右** | M3508 | C620 | **CAN2** | 2 | 0x202 | `SHOOTER_FRICTION_RIGHT_ID` |
| **拨弹轮** | M2006 | C610 | **CAN2** | 3 | 0x203 | `SHOOTER_FEEDER_ID` |

> ⚠️ **C620 和 C610 不能搞混**：它们的电流满量程不同（20A / 10A），
> 代码按 `M2006 → C610`、`M3508 → C620` 自动区分。把 M2006 当 M3508 写就会限幅错一倍。
>
> ⚠️ **两条 CAN 总线两端都要 120Ω 终端电阻**（C 板自带一个，另一头要接）。

### 0.2 遥控器通道分工（DBUS）

> ★ **V2.1 起通道有调整**：yaw 与 pitch 都改到右摇杆，左上角拨轮空出来了。

| 输入 | 用途 | 配置 |
|---|---|---|
| **右摇杆左右** | **云台 yaw** | `gimbal_ch`（默认 **0**）|
| **右摇杆上下** | **云台 pitch 俯仰** | `pitch_ch`（默认 **1**）|
| 左摇杆垂直 | 底盘前后 | `CHASSIS_RC_VX_CH`（默认 3）|
| 左摇杆水平 | 底盘左右 / 小陀螺方向 | `CHASSIS_RC_VY_CH`、`CHASSIS_SPIN_DIR_CH` |
| ~~右摇杆左右~~ | **底盘手动自转已关闭**（`CHASSIS_RC_W_ENABLE=0`），该通道只给 yaw | 想恢复改成 1 |
| 左上角拨轮 | **已空出**（V2.1 前是 pitch）| 想用它当拨弹扳机见 `shooter_config.h` 注释 |
| **sw1**（左拨杆）| 底盘模式：上=跟随 中=手动 下=小陀螺 | `chassis_control.c` |
| **sw2**（右拨杆）| **射击，自上到下**：上=**仅摩擦轮** 中=**无** 下=**摩擦轮+拨弹盘** | `shooter_config.h` |

## 2. 上电自检（不接遥控器、不接电机也能做）

上电前：**把枪管摆到水平**（pitch 零点就是上电这一瞬间的姿态，见第 4.4 节）。

| # | 现象 | 不对就查 |
|---|---|---|
| 1 | 绿灯常亮，红灯 800ms 闪一次 | `LED_Init` 第 4 个参数（低电平点亮传 1）、PH10/11/12 |
| 2 | 开机音乐响一遍 | PD14 / TIM4_CH3；`Buzzer_Init` 传的是 `TIM4_CLK`（84MHz）|
| 3 | 串口助手（115200, 8N1）收到 `SERIALPLOT OK` | USART1 = PA9(TX)/PB7(RX)；USB-TTL 的 TX 接板子 RX |
| 4 | 放平后串口能看到 `pitch ≈ 0`（切模式 0）| BMI088：`user_bmi088.accel_id == 0x1E && gyro_id == 0x0F` |

> ⚠️ 上电后**保持静止约 1 秒**，BMI088 要跑完 1000 次陀螺零偏标定，这期间 `gyro` 输出为 0。

**第 3 步是最重要的分水岭**：如果这句 ASCII 都没有，说明串口链路或板子根本没起来，
后面所有图都不用看了 —— 先解决这个。

## 3. 连上串口绘图 / 在线调参

**主用 SerialPlot（hyOzd 那个 Qt 上位机）。** 本工程的帧格式和原 A 板工程**完全没变**，
所以 SerialPlot 里原来的配置**照旧能用、不用重配**。下面 3.1 只是给你核对用的。

### 3.1 SerialPlot 帧格式（和原工程一致，未改动）

固件发出的帧（`user_serialplot.c`，开关在 `user_serialplot.h`）：

```
0xAB + N × float32(小端) + 1 字节累加和
```

对应 SerialPlot 的 **Custom frame** 模式，参数应为：

| SerialPlot 面板项 | 值 |
|---|---|
| Frame start（帧头） | `AB`（1 字节）|
| Fixed size | 0 |
| Number of channels | **N（随绘图模式变，见 3.3）** |
| Data type | `float` / 32 位浮点 |
| Endianness | Little endian（小端）|
| Checksum | 累加和，在各通道数据之后 |

> 如果你原来是用 SerialPlot 的 **Simple binary** 模式跑通的（那个模式只有帧头 + 纯数据、
> 没有校验和），说明它靠"扫帧头"同步、把校验和字节当帧间噪声跳过了 —— 一样能跑。
> 想改成这种最简格式就把 `user_serialplot.h` 的 `SERIALPLOT_CHECKSUM_ENABLE` 改成 `0`。
> **不改就保持原样，最稳。**

### 3.2 波特率

USART1 = **115200**，8 数据位 / 无校验 / 1 停止位。

> ⚠️ 板子端发 100Hz。8 通道（模式 1/4）时已占了约一半带宽。
> 以后想加通道或提刷新率，要把 USART1 提到 921600（CubeMX 和上位机一起改）。

### 3.3 ★ 换绘图模式时唯一要改的东西：通道数

原来绘图模式是编译期写死在 `chassis_config.h` 的宏里的。**现在可以在线切**（发 `plot_mode=N#`），
看不同模块不用再改宏重新编译。但是 —— **SerialPlot 那边的通道数要跟着改**。

| 模式 | 通道数 | 通道含义 | 用途 |
|---|---|---|---|
| 0 | **4** | `yaw pitch omega vx` | 姿态 / IMU |
| 1 | **8** | `FL/FR/RL/RR` 各 `tgt fdb` | 底盘 4 轮转速 |
| 2 | **5** | `gyaw gtgt gimu gcmd gspd` | 云台 yaw（**固件默认**）|
| **3** | **6** | `pitch ptgt pspd pid_i psd_i pcur` | **云台 pitch** |
| **4** | **12** | `frpm frpm_f frpm_t ferr fcur bpitch bv0 fstate online ready can1_rx can2_rx` | **射击机构 + CAN 总线排错** |

用法：**发 `plot_mode=3#` → 在 SerialPlot 里把通道数改成 6 → 重新 Open 串口**
（通道数改了必须重开，否则还按旧通道数解析，波形是错的）。

### 3.4 在线调参指令清单（SerialPlot 的 Command 面板直接用）

格式就是 `变量名=值#`。在 SerialPlot 的 **Commands** 面板里按 **ASCII** 类型定义：
带值的命令用 `%` 占位（如 `wheel_kp=%#`）；不确定就用固定值写法（命令名 `kp15`、内容 `wheel_kp=15#`）。

```
# ---- 绘图通道切换（不用重新编译固件）----
plot_mode=0#        姿态
plot_mode=1#        底盘 4 轮
plot_mode=2#        云台 yaw
plot_mode=3#        云台 pitch
plot_mode=4#        射击机构

# ---- 底盘 ----
test_wheel=0#       单轮测试选哪个轮
test_rpm=1000#      单轮测试转速
wheel_kp=15#   wheel_ki=0.15#   wheel_kd=0#
rev_fl=1#  rev_fr=-1#  rev_rl=1#  rev_rr=-1#     装反了改 -1
spin_w=4#   omega_dir=1#   dead=10#              小陀螺 / 方向 / 摇杆死区
head_kp=0.05#  head_ki=0#  head_kd=0.3#          跟随环
src_protect=1#                                   航向源保护

# ---- 云台 yaw（★ 抗惯性：先加阻尼 gimbal_world_kd，再提 gimbal_world_kp）----
gimbal_ch=0#         遥控通道（0=右摇杆左右 = yaw）
pitch_ch=1#          pitch 通道（1=右摇杆上下）
gimbal_max_w=6#      满杆角速度
gimbal_world_kd=0.28# 陀螺阻尼 RPM/(deg/s)（运动学值 1/6；偏软加到 0.33，抖就降）
gimbal_world_dead=0.3# 外环死区 deg（治"停着不动也慢慢抖"；IMU yaw 无绝对参考会漂移）
gimbal_world_kp=2.5# 锁世界位置环增益（τ≈6/kp 秒；1.0 太软，2.5 已加硬，别再往 3.0 那次冲）
gimbal_ff=1.0#       底盘角速度前馈（运动学正确值就是 1.0）
gimbal_kp=38#  gimbal_ki=0#  gimbal_kd=1#
        ★★★ 不硬的第一嫌疑不是增益而是【电流权限】：GIMBAL_YAW_MAX_OUT 原来 3000，
            只有满量程 ±16384 的 18%（0.55A / 0.41N·m），V2.2 已提到 12000（2.2A / 1.6N·m）。
            改完再调增益才有意义；想更激进可到 16384（满量程 3A / 72W）。
            在线可调：gimbal_max_out=16384#
        ⚠️⚠️ gimbal_ki 必须保持 0：这个速度环用老 user_pid.c（Iout += ki*err，没有 dt），
           被 1kHz 反馈调用 -> 等效积分增益 = ki×1000；再叠加 rotor_speed 是整数
           （静止时在 0/±1 之间跳），Ki>0 立刻形成【静止极限环】= 刚上电就慢慢抖。
           要刚度请用 gimbal_world_kp / gimbal_world_kd。

# ---- 云台 pitch（★ 顶重力的是【内环】积分 pitch_spd_ki）----
pitch_dead=30#       拨轮死区
pitch_max_w=120#     满拨轮角速度 deg/s
pitch_auto=0#        0=拨轮控制  1=由弹道解算给目标
pitch_ang_kp=12#   pitch_ang_ki=2#    pitch_ang_kd=0.2#  pitch_ang_kf=0#
pitch_ang_dz=0.15# pitch_ang_da=0.4#  pitch_ang_df=1#
pitch_ang_ia=6#    pitch_ang_ib=24#   pitch_ang_is=30#
pitch_ang_mo=200#  pitch_ang_mi=60#   pitch_ang_md=60#
pitch_spd_kp=30#   pitch_spd_ki=300#  pitch_spd_kd=0#
pitch_spd_da=0.5#  pitch_spd_df=1#    pitch_spd_zb=0#    ← zb 必须保持 0
pitch_spd_mo=8000# pitch_spd_mi=6000# pitch_spd_md=1500#

# ---- 射击机构 ----
fire_rpm=6000#       发射时摩擦轮转速
fire_kp=20#  fire_ki=0.5#  fire_kd=0#            （改左轮，自动同步右轮）
step_deg=45#         一步走多少【拨盘】角度（默认 360/8 弹位）
fire_int=120#        连发间隔 ms
feed_ang_kp=6#    feed_ang_kd=0.2#              拨弹轮位置外环
feed_spd_kp=8#    feed_spd_ki=0.3#              拨弹轮速度内环

# ---- 弹道解算 ----
dist=4.5#            目标水平距离 m
height=0#            目标相对枪口高度差 m（高了为正）
auto_aim=1#          把解算结果写进 pitch 目标角
v0_k=0.004#  v0_b=4.0#     摩擦轮转速 -> 弹丸初速 的线性模型（必须实测标定）
```

> ⚠️ `plot_mode` 一改**通道数就变了**，SerialPlot 里要同步改并重新打开串口。
>
> ⚠️ `pitch_spd_zb`（零位积分泄放）**正常必须保持 0** —— 开了会把顶重力的积分放掉，枪管下沉。
>
> ★ 指令里**允许有空格和换行**：固件解析时会自动去掉每条指令首尾的空白字符，
> 所以 SerialPlot 如果给指令补了 `\r\n` 也不影响（这是这次顺手加宽容度修的地方）。

## 4. 分模块验证（严格按这个顺序）

> ### ★ 第一次上机，建议只做这 4 步就收工
>
> 别指望一次把 6 个模块全调完 —— 每一步出问题都会污染后面。
>
> | 第一次 | 做什么 | 判定"今天算成功" |
> |---|---|---|
> | 1 | 第 2 节 上电自检 | 灯闪、音乐响、串口出 `SERIALPLOT OK` |
> | 2 | 4.1 遥控器 | SerialPlot 上 6 个通道都跟着动 |
> | 3 | 4.2 云台 yaw | 摇杆能转、小陀螺锁得住世界 |
> | 4 | 4.4 云台 pitch（**只测软限位和方向**）| 拨轮能拨动、到限位自动停、松手不下沉 |
>
> 底盘（4.3）、射击（4.5）、弹道（4.6）留到第二次。射击一定要在 pitch 稳了之后再做。
>
> **任何一步不过，就停在那里别往下走** —— 把"哪一步 / 什么现象 / 串口波形截图"发我。

每一步都有**操作 / 看什么 / 通过判据 / 不对改什么**。不要跳步 —— 后面每一步都依赖前面。

### 4.1 遥控器（DBUS）

| | |
|---|---|
| **接线** | USART3：PC10(TX)/PC11(RX)。**必须配成 Word Length = 9 Bits + Even 校验** |
| **操作** | 打开遥控器，切模式 0 或 2，推各个摇杆/拨杆 |
| **看什么** | 波形跟着动 |
| **通过判据** | 6 个通道（4 摇杆 + 2 拨杆）+ 拨轮都能看到变化；打杆方向与物理方向一致 |
| **不对改什么** | 完全没反应 → 先查 USART3 是否 9bit+EVEN（配成 8N1 是最常见的错）；部分通道不动 → 拨杆没拨到位 |

### 4.2 云台 yaw

| | |
|---|---|
| **前置** | 上电时云台要对准车头方向（yaw 零点） |
| **操作** | 切模式 2；推**右摇杆左右**；再把底盘模式切到「小陀螺」 |
| **看什么** | `gyaw`(云台相对底盘角) `gtgt`(世界目标角) `gimu`(IMU实测) `gcmd/gspd`(目标/实际转速) |
| **通过判据** | ① 摇杆能把云台转到指哪打哪<br>② 小陀螺自转时 `gtgt` 与 `gimu` 贴合（锁世界成功）<br>③ `gcmd` 与 `gspd` 贴合（速度环跟得上）|
| **不对改什么** | 转反了 → `GIMBAL_YAW_DIR`；抖/振荡 → `gimbal_kp`；跟不上 → `gimbal_kp` 加大；锁不住世界 → `gimbal_world_kp`、`gimbal_ff` |
| **★ 刚上电就慢慢抖（静止震荡）** | 按这个顺序二分，**每次只改一个**：<br>① `gimbal_ki=0#` —— **最常见**。这个环用老 `user_pid.c`（无 dt）+ 1kHz 调用 + 整数 RPM 反馈，Ki>0 必成静止极限环<br>② `gimbal_world_dead=1#` —— 加大外环死区。IMU 的 yaw 无绝对参考会缓慢漂移，外环追漂移就会"停着也抖"（默认 0.3°，可加到 0.5~1.0）<br>③ `gimbal_world_kd=0#` —— 排掉陀螺阻尼（若变好说明阻尼相位/符号有问题）<br>④ `gimbal_world_kp=1#` —— 退回原来更软的增益<br>⑤ `gimbal_ff=0.3#` —— 退回原来的前馈量<br>⑥ 以上都不行 → `plot_mode=2#` 看 `gimu`：若它自己就在缓慢漂移，是 IMU 零偏（互补滤波无绝对偏航参考，属固有现象；要根治需启用板载 IST8310 磁力计给偏航一个绝对参考）|

### 4.3 底盘

| | |
|---|---|
| **操作** | 切模式 1；`test_wheel=0` `test_rpm=1000` 先单轮试，再推左摇杆 |
| **看什么** | 4 轮的 `tgt` 与 `fdb` |
| **通过判据** | ① 单轮能按 `test_rpm` 转，符号对<br>② 推杆时 4 轮 `fdb` 都跟上 `tgt`<br>③ 整车前进/后退/平移方向正确 |
| **不对改什么** | 单个轮反了 → `rev_fl/rev_fr/rev_rl/rev_rr` 改成 -1；跟不跟得上 → `wheel_kp/ki/kd`；**平移方向整体错** → 查 `CHASSIS_MECANUM` 的轮序与 `chassis_config.h` |

> ⚠️ 这一步之后，**注意有个新行为**：把某个轮子的反馈线拔掉，那个轮子会**立刻停**（掉线保护）。
> 以前的代码是继续按最后的电流跑 —— 这是这次修的安全问题，不是 bug。

### 4.4 云台 pitch（★ 最需要耐心的一步）

| | |
|---|---|
| **前置** | **上电前把枪管摆到水平**。如果上电时不是水平，量出实际角度填进 `GIMBAL_PITCH_ZERO_BIAS_DEG` |
| **操作** | 切模式 3；推**右摇杆上下** |
| **看什么** | `pitch`(实际角) `ptgt`(目标角) `pspd`(转速) `pid_i`(外环积分) `psd_i`(内环积分) `pcur`(电流) |
| **通过判据** | ① 上电后 `pitch ≈ 0`<br>② 拨轮能把 pitch 拨动，**到 ±限位自动停住不硬顶**<br>③ 松手后枪管**稳稳停住、不慢慢下沉**<br>④ **`psd_i`（内环积分）稳定在一个非零值上顶着重力**，`pid_i` 接近 0 |
| **不对改什么** | 见下面的"pitch 专项排查" |

**pitch 专项排查**：

| 现象 | 原因 | 改什么 |
|---|---|---|
| 摇杆方向反了 | 方向 | `GIMBAL_PITCH_RC_DIR` 改成 -1（在线调 `pitch_ch` 可换通道）|
| 上电后 `pitch` 不是 0 | 上电姿态不对 | `GIMBAL_PITCH_ZERO_BIAS_DEG`；**或上电时把枪管摆水平** |
| 软限位方向反了 | 正负号约定 | 把 `GIMBAL_PITCH_FORWARD_MAX_DEG=15` 与 `GIMBAL_PITCH_BACKWARD_MAX_DEG=30` **两个数值对调**（要的是向前俯 15°、向后仰 30°）|
| **不动时每 5~6 秒自己动一小下** | **不是静态震荡** —— IMU 的 yaw 是纯陀螺积分、无绝对参考，零偏约 0.05°/s 被外环跟随、再被 0.3° 死区量化成周期小修正 | ① 加大 `gimbal_world_dead`（0.5~1.0，间隔变长、单次幅度略大）② **根治：启用板载 IST8310 磁力计**给偏航绝对参考 |
| 松手后**慢慢往下沉** | ★ **内环积分不够顶重力** | 先加大 `pitch_spd_ki`（默认 300）；如果没效果，说明积分被限幅截住了，加大 `pitch_spd_mi`（默认 6000）和 `pitch_spd_mo`（默认 8000）|
| 到位后小幅抖动 | 死区太小 / D 项噪声 | `pitch_ang_dz`（死区）从 0.15 往上加；`pitch_ang_da` 减小（滤波更强）|
| 跟拨轮迟钝、发肉 | 外环增益不够 | `pitch_ang_kp` 加大；也可给 `pitch_ang_kf`（目标速度前馈）一点值 |
| 冲过头来回摆 | D 项不够或 P 太大 | 先降 `pitch_ang_kp`，再加 `pitch_ang_kd` |
| 到限位还在使劲（嗡响）| 积分饱和 | 软件限位已夹住目标角并带抗饱和；如果还有，减小 `pitch_ang_mi` |
| 一动就猛冲 | 首拍冲击 | **不应该出现**（本工程有首拍保护）。若出现，检查是不是把 `pitch_ang_kf` 设太大了 |

> ⚠️ **pitch 是绝对的相对标定**：每次上电姿态必须一致，否则零点和软限位全都漂。
>
> ⚠️ **千万不要把 `pitch_spd_zb`（零位积分泄放）打开** —— 会把顶重力的积分泄放掉，枪管下沉。
>
> ⚠️ `pitch_*` 的 ki/kd 数值看起来比 `wheel_kp` 那套**大很多**，这是正常的：
> pitch 用的是增强 PID（有显式 `dt`，量纲带秒），底盘用的是 `user_pid.c`（dt 被隐含吸收）。
> 两套参数不可互相参照。

### 4.5 射击机构

| | |
|---|---|
| **操作** | 切模式 4；sw2 自上到下依次试：**上（仅摩擦轮）**→ 摩擦轮应起转但不拨弹；**中（无）**→ 全停；**下（摩擦轮+拨弹盘）**→ 摩擦轮起转且连续拨弹 |
| **看什么** | `frpm`(原始转速) `frpm_f`(滤波后) `frpm_t`(目标) `ferr`(拨弹轮位置误差) `fcur`(滤波后电流) `fstate`(状态) `online`(三电机反馈) `ready`(是否到转速) |
| **通过判据** | ① `fstate` 按 `0 → 1(SPINUP) → 2(FIRE)` 流转，拨回停火回 0<br>② **`online` = 7**（bit0 左轮 / bit1 右轮 / bit2 拨弹轮，三个都要有反馈）<br>③ `frpm_f` 收敛到 `frpm_t`（= `fire_rpm` 默认 6000）<br>④ `frpm` 与 `frpm_f` 有差别但趋势一致（**这就是 FIR 滤波在工作**）<br>⑤ 单发档：每拨上去一次，`ferr` 出现一个尖峰然后**回到 0**（走了一整步并停稳）<br>⑥ 摩擦轮方向是把弹丸往外送，不是往里吸 |
| **★ 拨杆无反应时按这个表判** | 先看 **`can2_rx`** 的上涨速率（原始收帧数，不看 ID）：<br>**CAN2 有 4 个电调时约 +4000/s**（pitch + 2 摩擦轮 + 拨弹轮），**只有 pitch 时约 +1000/s**<br>① `can2_rx` 只按 ~1000/s 涨 → 那 3 个电调**根本没在发报文**：查 CAN2 接线 / 24V 供电 / **ESC ID**<br>② `can2_rx` 约 +4000/s 但 `online`=0 → 报文在发、ID 对不上 → **ESC ID 配错**（左1 右2 拨弹3）<br>③ `online`=7 但 `frpm`=0 → 有反馈也在发指令，电机不转 → 查电调使能 / 电机相线<br>④ `fstate` 恒为 0 → 遥控 sw2 档位没识别（上=仅摩擦轮 / 中=无 / 下=摩擦轮+拨弹盘；注意 DBUS 编码是 上=1 下=2 中=3）|
| **不对改什么** | 见下 |

**射击专项排查**：

| 现象 | 原因 | 改什么 |
|---|---|---|
| 摩擦轮方向反了 | 对装方向 | `SHOOTER_FRICTION_LEFT_DIR` / `_RIGHT_DIR` 改一个为 -1 |
| 摩擦轮不转 / `fstate` 卡在 0 | sw2 档位没识别 | 检查 `SHOOTER_SW2_FRICTION_ONLY/FIRE/STOP` 的档位编码（**上=1 下=2 中=3**，别按 1/2/3 顺序想）|
| `fstate` 停在 1 不动 | 转速到不了位 | 看 `frpm_f` 是不是一直离 `fire_rpm` 很远 → 加大 `fire_kp/ki`；或降 `fire_rpm` |
| `frpm_f` 上不去 | 摩擦轮功率不够 | `SHOOTER_FRICTION_POWER_MAX`（默认 60W）；或 `fire_kp` |
| 拨弹轮方向反了 | 喂弹方向 | `SHOOTER_FEEDER_DIR` 改成 -1 |
| 拨弹不到位 / 过头 | 步长或环增益 | `step_deg`（默认 45°=360/8 弹位）；`feed_ang_kp`；`SHOOTER_FEEDER_SLOTS` 要对上你的拨盘弹位数 |
| `ferr` 收敛很慢、软绵绵 | 内环太弱 | `feed_spd_kp/ki` 加大 |
| 到位后来回振荡 | 外环太强 | 降 `feed_ang_kp`，加 `feed_ang_kd` |
| **老是误判卡弹反转** | 卡弹判据太敏感 | 加大 `SHOOTER_JAM_CURRENT`；加大 `SHOOTER_JAM_MS`；加大 `SHOOTER_JAM_ERR_DEG` |
| **真卡弹了却不反转** | 判据太钝 | 减小上面三个；或看 `fcur` 到底有没有抬头 |

> ★ **卡弹判据是"位置没跟上 **且** 电流大，且同时持续一段时间"**。
> 只看电流会被拨盘的机械冲击误触发，所以故意做成两个条件。
>
> ★ 拨弹轮用的是 `Rotor_angle`（多圈角度）+ 串级。**对外参数都用"拨盘角"**，
> 内部自动乘 36:1 减速比换算成转子角（M2006 编码器反馈的是转子角）。
> 所以 `step_deg=45` 表示拨盘转 45°，转子实际转 1620°。

### 4.6 弹道解算 + 自动瞄准

| | |
|---|---|
| **前置** | 4.4 的 pitch 已经调稳，4.5 的射击已经能正常打 |
| **操作** | 切模式 4；`dist=3#`（先给 3 米）；`auto_aim=1#` |
| **看什么** | `bpitch`(解算出的俯仰角) `bv0`(解算用的弹丸初速) `ptgt`(实际发给 pitch 的目标角，模式 3 看) |
| **通过判据** | ① `bv0` 随摩擦轮转速变化（转速高 → `bv0` 大）<br>② `bpitch` 是**正角度**（要抬枪），且随 `dist` 增大而增大<br>③ `ptgt` 跟着 `bpitch` 走，枪管实际抬起来 |
| **不对改什么** | `bv0` 不对 → 标定 `v0_k` / `v0_b`（见下）；`bpitch` 是负的/很怪 → 查 `dist` 和 `height` 的符号 |

**标定弹速模型**（必须做，否则弹道解算不准）：

1. 打两发不同的 `fire_rpm`（例如 3500 和 6000），用测速仪测出膛速度（或者用落点反推）。
2. 代入线性模型解出系数：

```
v0 = v0_b + v0_k × 摩擦轮转速(RPM)

设测到：3500RPM → v1，6000RPM → v2
  v0_k = (v2 - v1) / (6000 - 3500)
  v0_b = v1 - v0_k × 3500
```

3. 在线写进去：`v0_k=0.0043#` `v0_b=3.2#`

> ⚠️ 默认值（`v0_k=0.004`、`v0_b=4.0`，对应 3500RPM→18m/s、6000RPM→28m/s）只是**占位值**，
> 必须按你自己的摩擦轮/弹丸实测替换。
>
> ⚠️ 弹道模型**不含空气阻力**，只做重力补偿。远距离（>6~8m）会有系统偏差，
> 能靠 `v0_k/v0_b` 的标定吸收一部分，但不能全吸收。

## 5. 参数整定顺序（在线调参，不用反复烧录）

```
底盘：  wheel_kp → wheel_ki → wheel_kd      然后 rev_fl/fr/rl/rr 标方向
yaw ：  gimbal_world_kd（★先加阻尼）→ gimbal_world_kp（再提增益）→ gimbal_ff=1.0
        → gimbal_kp → gimbal_ki → gimbal_kd
        ⚠️ 顺序不能反：先提 world_kp 必振荡。τ ≈ 6/world_kp（world_kp=3 → τ≈2s）
pitch： pitch_spd_kp → pitch_spd_ki(★顶重力) → pitch_ang_kp → pitch_ang_kd
       最后视情况 pitch_ang_kf(前馈) / pitch_ang_dz(死区) / pitch_ang_da(D低通)
射击：  fire_kp → fire_ki                    然后 feed_spd_kp/ki → feed_ang_kp → feed_ang_kd
弹道：  v0_k / v0_b 标定，dist / height 实给
```

**共同原则**：先内环后外环；每次都只改一个参数；P 加到刚好开始振荡，然后退回 70%，
再补 I 消静差，最后用 D 压超调。

## 6. 整机联调

前面 6 步都过了以后：

1. `plot_mode` 回 2（或 0），底盘模式切「小陀螺」，开火 → 看整车是否稳。
2. 检查**掉线行为**：逐个拔掉电机反馈线，确认对应电机立刻停、且其他电机不受影响。
3. 检查**过温降额**：`DJI_MOTOR_TEMP_LIMIT_ENABLE` 默认开（70℃ 起降额、85℃ 断输出）。
   如果嫌它打扰调试，改成 0。
4. 检查**遥控断线**：关遥控器 → 底盘应进入保护（按 `CHASSIS_SOURCE_LOST_STOP` 决定是否全停）。
5. 上机飞行前，确认是 **Release** 构建。

## 7. 故障速查

| 症状 | 最可能的原因 |
|---|---|
| 串口收不到 `SERIALPLOT OK` | USART1 接线（TX↔RX 要交叉）、波特率不是 115200、板子没起来 |
| 遥控器完全没反应 | USART3 **必须 9 Bits + Even**；配成 8N1 是最常见的错 |
| 某个电机完全没反馈 | CAN 终端电阻；ESC ID 配错；C620/C610 型号搞混 |
| 波形不动但串口有输出 | 通道数不匹配（脚本模式号 vs 固件 `plot_mode`）；换个模式号重启脚本 |
| 换了模式号脚本报 `模式 N 不存在` | 只支持 0~4 |
| 电机一上电就猛转 | 控制模式/零点没标定（pitch 上电姿态不对）；或 `*_DIR` 方向配错 |
| 电机反馈断了反而一直转 | **不应该出现**（掉线保护已修）。若出现，检查是不是绕过 `DJI_Motor_Execute` 直接发的帧 |
| pitch 每次上电行为都不一样 | 上电姿态不一致 → 零点漂（这是相对标定的固有限制）|
| 烧录报 "build is not a directory" | `build/` 没配置成功，**不是 ST-Link 问题**，重新编译一次 |

## 8. 附：CAN 负载（为什么 pitch 挂 CAN2）

按 8 字节标准帧约 130 位（含位填充）、反馈 1kHz、发送 500Hz 估算：

| 方案 | CAN1 | CAN2 |
|---|---|---|
| 只有底盘 + yaw | 6000 帧/s ≈ **78%** | 0% |
| pitch 挂 CAN1 | 7000 帧/s ≈ **91%** ❌ | — |
| **pitch 挂 CAN2（当前）** | 6000 帧/s ≈ **78%** | 6000 帧/s ≈ **78%** |

> **CAN1 本身 78% 就偏高**（一般建议 ≤70~80%）。以后如果 CAN 出问题，
> 第一个该动的是把底盘 1~2 个轮子挪到 CAN2 平衡负载，而不是压缩别的。
>
> 发送是 500Hz（`MOTOR_EXECUTE_PERIOD = 2`），所以 pitch/拨弹的电流指令是 2ms 更新一次。
> 想更快就把 `MOTOR_EXECUTE_PERIOD` 改成 1（代价是每条总线多 500 帧/s）。
